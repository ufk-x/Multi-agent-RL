## 🎯 环境特性

### 状态空间 (9维)
```python
[θ1, θ2,           # 关节角度 (2)
 ω1, ω2,           # 关节角速度 (2)
 Δx, Δy,           # 末端到目标的相对位置 (2)
 Δx_obs, Δy_obs, d_obs]  # 末端到障碍物的相对位置和距离 (3)
```

### 动作空间 (2维)
```python
[τ1, τ2]  # 两个关节的扭矩，范围 [-2.0, 2.0]
```

### 奖励函数
- ✅ **到达目标** (距离 < 0.1): +100
- ❌ **碰撞障碍物**: -50
- 📉 **距离惩罚**: -0.1 × distance_to_target
- 📉 **动作惩罚**: -0.01 × (τ1² + τ2²)
- 🎯 **接近奖励** (距离 < 0.5): +0.5

## 🔧 关键技术实现

### 1. 正运动学
```python
# 计算末端位置
x = l1*cos(θ1) + l2*cos(θ1+θ2)
y = l1*sin(θ1) + l2*sin(θ1+θ2)
```

### 2. 碰撞检测
- 检查末端执行器与障碍物的距离
- 检查中间关节与障碍物的距离
- 检查连杆线段与障碍物的最短距离

### 3. PPO算法
- 使用高斯策略输出连续动作
- 截断机制防止策略更新过大
- Actor-Critic架构

## 💡 使用建议

### 训练技巧
1. **首次运行**: 使用默认参数训练2000-3000个episodes
2. **调参**: 如果不收敛，尝试减小学习率或增加隐藏层维度
3. **监控**: 观察训练曲线，确保回报稳步上升

### 常见问题
1. **频繁碰撞**: 增加碰撞惩罚权重
2. **运动不平滑**: 增加动作惩罚权重
3. **训练慢**: 检查GPU是否可用，调整batch size
